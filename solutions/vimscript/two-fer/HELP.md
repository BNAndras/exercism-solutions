# Help

## A tesztek futtatása

Nyisd meg a megoldásodat:

```bash
$ vim <exercise>.vim
```

Ahhoz, hogy a fájl globális függvényei elérhetővé váljanak a Vimben, töltsd be az aktuális fájlt:

```
:source %
```

Futtasd a teszteket:

```
:Vader <exercise>.vader
```

A `<exercise>` helyére írd a feladatod nevét.

## A megoldásod beküldése

A megoldásodat az `exercism submit two_fer.vim` paranccsal küldheted be.
Ez a parancs feltölti a megoldásodat az Exercism weboldalára, és kiírja a megoldás oldalának URL-jét.

Beküldhetsz hiányos megoldást is, amivel:

- megnézheted, hogyan oldották meg mások a feladatot
- segítséget kérhetsz egy mentortól

## Segítségre van szükséged?

Ha segítséget szeretnél a feladat megoldásához, nézd meg a következő oldalakat:

- A [Vim script kurzus dokumentációja](https://exercism.org/docs/tracks/vimscript)
- A [Vim script kurzus programozási kategóriája a fórumon](https://forum.exercism.org/c/programming/vimscript)
- Az [Exercism programozási kategóriája a fórumon](https://forum.exercism.org/c/programming/5)
- A [Gyakran ismételt kérdések](https://exercism.org/docs/using/faqs)

Ha ezek az erőforrások nem elégségesek, beküldheted a (hiányos) megoldásodat, hogy mentorálást kérj.

Ha elakadsz, az alábbi források egyikétől kérhetsz segítséget:

- [Learn Vimscript the Hard Way](http://learnvimscriptthehardway.stevelosh.com)
- [IBM DeveloperWorks: Scripting the Vim
  editor](http://www.ibm.com/developerworks/views/linux/libraryview.jsp?sort_order=asc&sort_by=Title&search_by=scripting+the+vim+editor)

- A [StackOverflow](http://stackoverflow.com/) segítségével rákereshetsz a problémádra, és megnézheted, hogy megválaszolták-e már. Kérdezhetsz is, és válaszolhatsz mások kérdéseire.
